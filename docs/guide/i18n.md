# Internationalisation and collection text

A locale change updates mounted components without reloading the page. `t()`
reads a reactive message table, so a component that renders translated text
updates when the table changes.

```html
<select (change)="setLocale($event.target.value)">
  <option *for="l of availableLocales; key: l.code" [value]="l.code"
          [.selected]="l.code === locale">{{ l.label }}</option>
</select>
```

Message bundles use nested or flat JSON keys. Keys beginning with `$` hold
translator notes and are skipped by the runtime and checker. Remote modules can
register their own bundles when they load.

The build gives each locale bundle a hash-named URL and long cache lifetime.
The manifest maps the declared locale pattern to those files. Development reads
the declared files directly. Fallback happens per key, so an incomplete Arabic
bundle uses English only for the missing messages.

`Intl.PluralRules` selects plural forms. `num`, `cur`, `dt`, and `rel`
format values for the active locale. The amount supplies its currency code;
the locale controls how that currency is written. RTL languages set the
document's `dir`, while layout uses logical CSS utilities.

`srl check messages` reads message references in application, library, and
collection source. It reports missing keys, placeholders a call does not
supply, untranslated entries, and unused entries. Missing keys and
placeholders fail the check.

Keep message keys in state when a value must outlive a render. A translated
sentence stored in a signal would stay in the old language.

## Adding a message

```bash
srl check messages
srl check messages --write
```

`--write` adds missing keys to the right default-language bundle. It uses
the key itself as temporary text so an untranslated message remains visible.
The author then writes the sentence. Computed key families, such as
`t('billing.view.' + name)`, are reported but cannot be extracted as one key.

The language server uses the same catalog. It underlines a misspelled key and
suggests a nearby one while the file is open.

## Text in shared components

A screen passes labels for its own data as translated properties.

```html
<ui-sidebar-toggle label="{{ t('a11y.toggleSidebar') }}">
<ui-table [.rows]="rows" caption="{{ t('nav.peopleStaff') }}"></ui-table>
```

A shared element names its own actions through
`source/components/internal/text.js`. Keys such as `ui.table.previous` and
`ui.filter.clear` come from the application's bundle.

```json
{ "ui": { "table": { "previous": "Previous page", "empty": "No rows found." } } }
```

The default resolver reads that bundle and reacts to locale changes. An
application with another dictionary can replace the resolver once.

```js
configureCollectionText({ resolve: (key) => myDictionary[key] });
```

An empty message is a deliberate empty label, while a missing one renders as
its key. Per-instance overrides remain available for `ui-table.emptyLabel`,
`ui-combobox.notFoundLabel`, and `ui-combobox.addTagLabel`.
